# 面对面翻译：对方语言可选（韩语、日语、英语）设计

状态：待用户批准。**【已定】** 是用户决定的，**【我定的】** 是执行者的判断，可以推翻。
本文是 `2026-11-27-face-to-face-design.md` 的增补：没提到的行为（一次说话的流程、中断、前后台、保存、历史记录等）沿用原设计。

## 目的

**【已定】** 旅游用。主要去日本、韩国，也要能和说英语的人交流。机主说中文，对方说日语、韩语或英语，双方各看自己语言的文字。

## 目标与不做的事

- **【已定】** 对方语言在日语、韩语、英语中选一种；机主一侧固定中文。
- **【已定】** 马来语这次不做（苹果不能翻译马来语；试过的开源模型质量不够）。
- 不做：其他语言（含听写接口才能识别的那批）、不含中文的语言组合、自动判断语言、朗读、会议字幕功能的任何改动。
- 反目标：为了加语言让现有的中韩对话或旧的历史记录出问题；出现联网代码；悄悄释放系统里已保留的识别语言。

## 做法的选择（用户已选 A）

1. **A（选中）：** 先做日、韩、英。三种都能用现有的识别接口（`SpeechTranscriber`），苹果翻译也支持；语言做成一张表。
2. B：一次做完苹果支持的 18 种。要再接听写接口、处理保留名额、写 18 套对方界面文字，大部分这次用不到也无法验证。

## 现状（代码里的事实）

- `ConversationSide` 只有 `chinese`、`korean` 两个值，语言信息和"哪一侧"绑在一起；界面文字、语言包列表、译者装配、历史记录标签都按这两个值写死。
- `ConversationRecorder` 固定写 `languageCodes: ["zh", "ko"]`；每句存 `speakerCode`（`"chinese"` / `"korean"`）。
- 拼接识别片段的规则已把假名和日文标点当作不加空格的字符。
- MacBook Air（macOS 26.6.1，**不是 iPhone**）查到：`ja-JP`、`ko-KR`、`en-US`、`zh-CN` 都在 `SpeechTranscriber` 支持列表中；`zh-Hans` 与 `ja`、`ko`、`en` 双向翻译为可下载。iPhone 上未核对。
- 同时可保留的识别语言上限在 Mac 上是 5；本方案最多用到 4 种（中、英、韩、日；英语与会议字幕共用）。iPhone 上限未确认。
- 面对面功能至今没有在真机上验收过。

## 界面

```
┌──────────────────┐
│  整块倒置，朝向对方 │
│  日文对话记录      │
│  [ 話す ]         │
├──────────────────┤
│ 对方语言：日语 ▾   │
│  中文对话记录      │
│  [ 我说中文 ]  ✕  │
└──────────────────┘
```

- **【我定的】** 语言选择在中文一半的顶部，同时也出现在语言包检查页（某种语言缺包或不支持时能换回别的）。选项显示中文名和本族名（如"日语 日本語"），方便让对方指认。
- **【我定的】** 只有空闲时能换；正在听、收尾、翻译中时不可用。
- **【我定的】** 记住上次选择；首次默认韩语（与现在行为一致）。
- **【我定的】** 换语言就开始一段新对话：屏幕清空，之后的句子记到新的历史记录里；之前的记录保留。原因：对方半屏只用一种语言，旧句子是另一种语言的。重新选当前语言不做任何事。
- **【我定的】** 对方半屏的按钮和提示用对方语言（日、韩、英各一套）。由执行者撰写，没有母语者校对。
- **【我定的】** 对方半屏按对方语言排版，避免日文汉字显示成中文字形。
- 中文一半的原因提示仍是中文，规则同原设计。

## 语言包

- 每种对方语言需要四样：中文识别包、该语言识别包、中→该语言翻译、该语言→中翻译。只检查当前选中的语言。
- 换语言后重新检查；缺什么列什么，下载方式同现在。切换时正在进行的下载按"取消"处理。
- **【我定的】** 不做"一次下载全部语言"。出国前在有网时把要用的语言各选一次并下载。
- 保留名额超限时显示系统给出的原因，不释放任何语言。
- 英语固定用 `en-US`，日语 `ja-JP`，韩语 `ko-KR`，中文 `zh-CN`；翻译语言为 `zh-Hans` 与 `ja` / `ko` / `en`，检查、下载、翻译用同一处定义。

## 保存与历史记录

- 存储结构不变，不做数据迁移。`languageCodes` 按实际语言写（如 `["zh","ja"]`）；对方的 `speakerCode` 为 `korean`（沿用）、`japanese`、`english`。
- 历史记录和导出里的标签为"中文方""韩语方""日语方""英语方"；旧记录显示与现在完全一致。

## 约束

沿用项目现有约束：Swift 6、警告当错误、单个源文件不超过 200 行、无第三方依赖、无网络代码、CI 编译 iOS 26/27 部分。

## 验收（真机，结果由用户填写）

对日、韩、英每一种：联网下载语言包 → 开飞行模式 → 两个方向各说三句旅行常用语，识别和译文都出现。另外：换语言后屏幕清空、两条历史记录标签正确；杀掉 App 重开仍是上次的语言；升级后旧的中韩记录照常打开；会议字幕功能照常。

译文好不好是单独记录的观察结果，不是本改动通过的条件（没有测过日中翻译质量）。
